SILENTSYSTEM

Collega Supabase

Il sito non contiene dati. Il registro vive su Supabase e l'accesso è protetto da email e password.

  1. Crea un progetto gratuito su supabase.com.
  2. Nel SQL Editor esegui supabase/schema.sql, poi private/seed.sql.
  3. In Authentication → Sign In / Providers disattiva le registrazioni e crea gli utenti da Users.
  4. Copia Project URL e anon / publishable key in assets/config.js.
export const SUPABASE_URL = 'https://xxxx.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
Leggi il README

La chiave pubblica è pensata per stare nel browser: la protezione dei dati è nelle policy RLS di Supabase. Non inserire mai la service_role key.
